## 操作方式

- WASD / 方向键: 移动
- 空格: 在纸箱格隐藏或离开纸箱
- F: 按住瞄准噪音落点，方向键 / WASD 调整方向，松开制造声响
- J: 按住进入麻醉枪瞄准和子弹时间，方向键 / WASD 调整方向，松开发射瞬发麻醉弹
- G: 跳过开局镜头
- 1-6: 选择关卡
- Enter: 开始 / 结算后继续
- Esc: 返回选关
- R: 重开当前关

## 玩法机制

- 纸箱隐藏可以避开远距离视野，但不能阻止同格抓捕。
- 噪音可以诱导附近守卫先疑惑，再前往噪音点搜索；玩家躲在纸箱内也可以按住 F 瞄准并制造声响，仍保持隐藏。
- 摄像头会旋转扫描，被看到会触发警戒并引导守卫搜索；摄像头视野使用独立的蓝紫色半透明范围显示。
- 麻醉枪弹药随关卡提升：第 1-2 关 1 发，第 3-4 关 2 发，第 5-6 关 3 发。按住 J 显示红色虚线瞄准并进入轻微子弹时间，松开 J 沿瞄准方向瞬发射线判定并显示短暂红色弹道；麻醉弹不能穿墙或穿过纸箱，命中第一个守卫后该守卫整关昏厥并显示 ZZZ。麻醉枪可以在纸箱内使用。
- 第 4、5、6 关加入门禁和钥匙。玩家必须先取得对应钥匙，才能通过对应门禁；第 6 关包含 A/B 两套钥匙门禁。
- 守卫头顶会显示状态：? 表示怀疑，! 表示发现，... 表示搜索，ZZZ 表示昏厥。
- 通关后会根据步数、警戒和道具使用显示路线评价。
- 右上角雷达显示玩家附近区域、目标方向、钥匙、门禁和守卫位置。
- 清醒守卫看到昏厥同伴时会进入搜索状态。
